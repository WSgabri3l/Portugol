# Portugol
## Exercício feitos durante as aulas de Lógica Computacional no Curso Informática para Internet no SENAI.

A linguagem utilizada foi o Portugol, uma pseudo-linguagem de programação projetada para ensinar conceitos básicos de lógica de programação e algoritmos de maneira acessível e intuitiva  para falantes de português.

Este arquivo contém as formas que utilizei para resolver exercícios de lógica de programação, entre eles:

- Sorteio de números da MegaCena
- Lista de Compras
- Simulações de Sistemas de Cadastramento
- Média de Notas
- Urna Eletrônica
- Organização de Números


Além de alguns desafios propostos pelo professor como:


- Jogo da Forca
- Jogo Batalha Naval
- Correção de distribuição de notas de um caixa eletrônico
